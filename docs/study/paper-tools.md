# 几个赶 ddl 的好用工具🔧

赶 ddl 的朋友们，你们还好吗？
接下来，我来推荐几个赶 ddl，写论文的好用工具🔧

::: warning 学术诚信与数据隐私

翻译、语法、改写、生成式 AI 和查重工具都不能替代作者判断，也不能用于掩盖抄袭或伪造原创性。使用前先确认课程、导师、期刊和研究项目的规则；引用他人观点仍须规范标注。不要把未公开论文、受试者信息、保密数据或他人作品上传到未经批准的第三方服务。

:::

## Google Translate 翻译器

<https://translate.google.com>

国际大厂出品，用过都知道。

## DeepL Translate 翻译器

<https://www.deepl.com/translator>

好用，长句翻译有时优于谷歌翻译。

## Grammarly （英文）语法检查器

<https://www.grammarly.com>

一键检查，10000字的论文也不用担心自己语法问题啦。

## 多语言支持语法检查器

* <https://www.websiteplanet.com/zh-hans/webtools/spell-checker>

## 秘塔写作猫 （中文）语法检查器

<https://xiezuocat.com/>

同样是一键检查，针对中文特别优化。

## QuillBot 同义转写

<https://quillbot.com/>

可辅助检查和比较英文改写表达。只有在课程或投稿规则允许时使用，并逐句核对含义、术语与引用；“降低重复率”不等于符合学术诚信要求。

## Mybib 参考格式化

<https://www.mybib.com/>

Reference 一键式操作，什么 GBT 7714-2015，APA，IEEE 格式都支持。

自动生成的作者、题名、卷期、页码和 DOI 仍需与原始文献逐项核对。

## Turnitin 查重

<https://www.turnitin.com/>

南科大图书馆购买了 Turnitin，但**学生不能据此自行申请个人教师账号**。根据图书馆当前公开的管理方式：

- 学位论文查重由研究生院或教学工作部授权院系秘书办理；
- 课程作业和博士资格考核查重仅在保障学位论文后、根据富余账号情况由院系老师申请；
- 教师账号面向教研、教学和研究序列老师；
- 学生如有期刊投稿查重需要，应联系本人导师。

具体安排见图书馆[《关于论文原创性检测工具 Turnitin 管理方式调整的公告》](https://lib.sustech.edu.cn/_s3/2024/0220/c58a7448/page.psp)和[工具与软件页面](https://lib.sustech.edu.cn/gjyrj_116/list.htm)。不要购买来历不明的“代查重”账号或把未公开稿件交给非授权人员；不同检测系统的相似度也不能直接互相换算。
