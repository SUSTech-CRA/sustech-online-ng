# 向境外院校或机构提供成绩单

> 不同院校对“申请人上传”“学校直接发送”“密封纸质件”和第三方认证的定义不同。请先保存接收方的官方要求，再选择下面对应的办理方式。

::: warning 个人信息安全
邮件中不要发送校园统一身份认证密码、自助终端密码或身份证完整号码。仅在接收方或学校业务部门明确要求时提供必要材料，并核对收件域名和隐私政策。
:::

## 本科生

### 接收方要求密封纸质件

1. 通过校内自助打印机开具成绩单；设备位置和开放情况请以当前[学生办事指南](https://sscsop.sustech.edu.cn/2256/list.htm)或现场指引为准。
2. 携带成绩单到南科大中心 304 办理信封封装和盖章封印。
3. 自行按接收方指定的邮寄方式寄出，并保留快递单号。

公开办事指南列出的办理时间为周一至周五 8:30–12:00、14:00–17:30。该指南发布于 2021 年，前往现场前建议在[学生办事指南](https://sscsop.sustech.edu.cn/2256/list.htm)确认是否有临时调整，或联系学生事务中心（0755-88010555）。

### 接收方接受电子件

如果接收方允许申请人自行上传，可按其要求提交学校开具的电子文件或纸质成绩单的合规扫描件。若接收方明确要求由学校邮箱直接发送，现有公开办事页面没有说明统一的默认代发流程；请使用学校邮箱联系教学工作部学生学习服务邮箱 `tao-sls@sustech.edu.cn`，附上接收方的官方要求、申请编号、收件地址和截止日期，先确认办理方式，再按回复补充材料。

请勿在首次咨询邮件中发送账号密码，也不要在没有明确要求时一次性附上身份证、毕业证和学位证扫描件。

## 研究生

2026 年研究生院已公布研究生电子成绩单服务。当前在校生可登录[教学管理与服务平台](https://tis.sustech.edu.cn/)，从“业务办理（研）”进入“电子成绩单”；学校[常用系统](https://www.sustech.edu.cn/zh/common-systems.html)同时列有[研究生电子签章系统](https://design.gs.sustech.edu.cn/)。生成文件后，应按接收方要求上传、发送或进行验证；电子文件不要自行修改或转制。

如系统无记录、已毕业后无法登录，或接收方必须由学校直接发送，请先联系研究生教学服务邮箱 `gs-edu@sustech.edu.cn`，说明姓名、学号、培养层次、接收方官方要求、申请编号和截止日期。收到回复前不必发送与问题无关的证件扫描件。

部分接收方可能要求在线验证电子成绩单，可使用接收方指定的平台；若其要求学信网验证，可前往[学信网电子成绩单验证平台](https://www.chsi.com.cn/cjdyz/index)。
