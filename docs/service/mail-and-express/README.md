# 📦邮件与快递收发

::: warning 信息时效

收发室、快递柜、服务时间和运营商会随宿舍安排及物业服务调整。本页不再把旧柜机数量、旧二维码或个人经验当作实时规则。寄件前请以物流平台、取件短信、学校邮件和现场标识为准。

:::

## 填写收件信息

学校公开地址为：**广东省深圳市南山区学苑大道 1088 号，邮编 518055**。

下单时还应填写所在书院、宿舍区、楼栋、房间或办公地点，并使用本人可及时接收通知的手机号。平台若能选择校内具体收发点，以其当前可选项为准；不要只填写“南方科技大学”，以免被分到错误区域。

## 收发室与快递柜

学校 2024 年发布的《总务服务指南》曾列出荔园、欣园、湖畔、慧园和新生宿舍等收发点。该指南适合用于了解服务结构，但不是实时点位表；旧页面所列的房间号、电话、开放时间、柜体编号和格口数量均可能已经变化。

到件后请按承运商或校内服务发送的通知前往指定位置。取件地点与地址栏不一致时，以最新的官方通知和现场分区为准，不要根据旧攻略自行前往另一栋楼。

取件时注意：

- 在承运商官方 App、小程序或客服电话中核对运单状态；
- 不向陌生链接填写校园账号、身份证照片、银行卡或验证码；
- 收到“超期费”“重新认证”“退款理赔”等消息时，先通过官方渠道核实；
- 发现外包装明显破损、渗漏或物品不符时，现场留存证据并联系承运商处理。

## 如何寄件

可在承运商官方 App 或小程序预约上门取件，也可到当前开放的校内收发点咨询。能否在快递柜自助寄件、哪些企业提供上门服务以及现场工作时间，以当日页面和现场说明为准。

根据现行《快递暂行条例》，寄件人应如实提供寄件人与收件人的姓名、地址、联系电话及物品信息；快递企业依法查验寄件人身份并验视内件。寄送前请不要提前完全封死包装，并确认物品不属于禁止或限制寄递范围。

## 异常件处理

### 显示已签收但没有取件通知

先在承运商官方渠道核对收件手机号、签收人和末端网点，并联系承运商客服。若物流记录显示已经进入校内但无法定位，再根据学校最新通知或现场服务台指引处理。

### 派送地点与填写地点不一致

向承运商提供运单号和完整收件信息，要求核对分拣结果。旧页面所写“未填写详细地址统一派到荔园 8 栋”以及“13 栋快件会移至 8 栋”等经验，不再作为当前规则。

### 需要联系学校服务部门

学校官网当前列出的总务后勤部联系方式为 **0755-88018856**、`fcso@sustech.edu.cn`。具体快递点若在短信、学校邮件或现场公布了更直接的服务电话，应优先使用该渠道。
