## 图书馆服务

除了常规的自习室与纸质书刊借阅服务外，图书馆还提供其他服务：
### 讨论间
可供小组讨论的隔音空间，一般需要提前预约，[预约系统地址（点此）](https://booking.lib.sustech.edu.cn/)。

讨论间开放范围、预约时段和临时使用规则以图书馆预约系统及现场标识为准。

### 电子数据库
图书馆数据库数量、授权范围和校外访问方式持续变化。请直接查看图书馆当前[数据库导航](https://lib.sustech.edu.cn/sjk/list.htm)和[校外访问说明](https://lib.sustech.edu.cn/xwfw_154/list.htm)，不要依赖本站保存的 2020 年数量或 2021 年单库深链。

### 图书馆荐购
可以通过以下任意方式荐购图书：
* 至图书馆服务台领取荐购单填写信息后交给服务台。
* 在图书馆[官网荐购页面](https://lib.sustech.edu.cn/dzjg/list.htm)填写荐购信息。
* 发送荐购信息至邮箱[lib_acq@sustech.edu.cn](mailto:lib_acq@sustech.edu.cn)荐购。

### 教工/学生订阅优惠

部分出版商可能提供教育优惠，但资格、价格、区域和续期规则由厂商决定。申请前在出版商官网核对当前条款，并优先确认图书馆数据库是否已经提供所需内容。
