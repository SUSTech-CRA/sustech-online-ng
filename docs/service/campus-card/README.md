# 💳校园卡

校园卡用于校内身份识别、消费及部分场所通行。卡片权限、充值渠道、补办费用、领取地点和开放时间都可能随系统升级或身份类型变化，请以校内系统显示和办事部门当次答复为准。

::: warning 保护账号与卡片

只从南科大官方域名、学校企业微信、支付宝官方校园服务入口或现场自助机办理业务。不要向他人提供校园卡密码、短信验证码或付款码，也不要安装声称可以“复制校园卡”“绕过门禁”的工具。

:::

## 电子校园卡与二维码

校内系统可提供校园卡二维码。使用时优先从学校企业微信中的“校园卡”入口进入；也可访问[校园卡二维码页面（需统一身份认证）](https://campuscard.sustech.edu.cn/epay/thirdconsume/qrcode)。

二维码相当于支付或身份凭证，不要截图转发，也不要在共享设备上保持登录。若入口无法使用，到[网上服务大厅](https://ehall.sustech.edu.cn/)搜索“校园卡”，或联系网络信息中心确认当前服务入口。

## 充值

常用方式包括学校企业微信中的校园卡服务、支付宝校园一卡通入口以及校内自助机。支付页面显示的到账时间、限额和支持卡种才是当次交易依据。

旧页面中的以下信息不再作为当前承诺：固定现金充值时段、“所有银行卡和信用卡均可”、充值后必须圈存、固定等待五分钟、“校园宝”公众号，以及办公接待卡特定金额的审批规则。涉及单位经费或接待卡时，应直接按网上服务大厅和财务部门的当前流程办理。

充值后余额未更新时：

1. 保留支付订单号，不要重复付款；
2. 在原支付渠道确认交易状态；
3. 按系统提示尝试同步或在自助机查询；
4. 仍未到账时，通过官方服务渠道提交订单时间、金额和脱敏后的交易信息。

## 挂失与补办

卡片遗失后应尽快在学校企业微信“校园卡”服务或当前可用的自助渠道挂失，避免继续产生消费或通行记录。

学校学生事务中心的公开办事目录当前仍列有“校园卡补办”。请从[卡证办理目录](https://sscsop.sustech.edu.cn/2743/list.htm)进入，核对最新办理方式、费用、地点、时间和领取通知。目录中的具体指南最早发布于 2021 年，若其页面与企业微信、网上服务大厅或现场公告不一致，以办事部门最新答复为准。

补卡后若消费或门禁功能未恢复，不要反复刷卡或尝试复制卡片；请携新卡和本人有效证件，到学生事务中心或行政服务大厅核验信息。

## 注销与身份变更

离校、离职或身份变化时，校园卡注销、余额处理和权限变更应纳入对应的离校或人事流程。先在[网上服务大厅](https://ehall.sustech.edu.cn/)查看本人待办，不沿用旧页面固定的窗口号或纸质审批说法。
