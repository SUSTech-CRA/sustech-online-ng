# 📶选择一台合适的路由器

by [@sparkcyf](https://github.com/sparkcyf)

::: warning 更新说明

## 先确认是否真的需要购买

学校无线网络能满足日常学习时，额外路由器往往只会增加干扰、双重 NAT 和维护成本。较常见的合理需求包括：

- 房间无线覆盖确实较弱，且更换位置、使用学校 AP 后仍无法解决；
- 台式机、开发板或存储设备需要稳定的有线局域网；
- 已合法办理运营商宽带，需要自备兼容的路由器；
- 需要隔离自己的实验设备或管理本地网络，但不会影响他人和校园网。

购买前先确认宿舍是否允许自建无线网络、墙上端口当前如何认证、运营商是否提供设备，以及出现故障时学校支持的边界。不要根据旧攻略假设端口一定是 1 Gbit/s、所有宿舍条件相同或个人路由器能改善校园出口速度。

## 不刷第三方固件

对大多数同学，选择仍在厂商安全支持期内的普通路由器更省心。比较时优先看：

1. **持续更新**：厂商是否提供清晰的固件下载、更新记录和安全公告；不要购买已经停止维护的旧款。
2. **实际接口**：先确认宿舍或宽带的真实速率，再决定是否需要千兆或 2.5G 网口；无线宣传速率不等于实际联网速度。
3. **覆盖而非参数堆叠**：天线数量、频宽和“AX/BE”数字不能单独决定隔墙表现。小空间通常不需要高价多节点 Mesh。
4. **兼容与安全**：确认常用设备支持的频段和加密方式，启用 WPA2/WPA3，设置独立管理密码并关闭不需要的远程管理。
5. **可恢复性**：优先选择可以导出配置、恢复出厂设置且售后渠道明确的型号。

旧页面列出的具体型号和“150 元左右”价格均已移除。促销和硬件版本变化很快，即使商品名相同，内部芯片或闪存也可能不同。

## 计划安装 OpenWrt

不要先买“网上说能刷”的型号，再寻找固件。应在付款前核对**完整型号、硬件版本和地区版本**：

1. 在 OpenWrt [Table of Hardware](https://openwrt.org/toh/views/toh_supported_since_target)确认该具体硬件版本受当前稳定版支持。
2. 在[固件选择器](https://firmware-selector.openwrt.org/)确认有对应镜像，并阅读设备专属安装与恢复说明。
3. 检查闪存、内存、无线芯片、网口布局和恢复方式是否满足需求。OpenWrt 官方表格也提醒，同一设备的可用闪存可能少于标称容量，部分无线芯片支持有限。
4. 首次刷写前保存原厂固件、配置和恢复说明。安装过程具有损坏设备或失去保修的风险，不使用与硬件版本不匹配的镜像。

OpenWrt 的安装方式因设备而异，通用教程不能替代[设备专属说明](https://openwrt.org/docs/guide-user/installation/start)。只想扩展有线端口或把设备当 AP 时，交换机或支持 AP 模式的普通路由器通常更简单；不必为了“软路由”固定购买某块过时开发板。

## 校园环境中的设置原则

- 先使用 AP/桥接等简单模式，只有明确需要时才启用路由、NAT 或 IPv6 中继；
- 不做多拨、MAC 冒用、认证绕过或会影响同楼层用户的 DHCP/RA 广播；
- 路由器管理界面不暴露到校园网或公网，及时安装安全更新；
- 出现大面积掉线、地址冲突或认证异常时，立即断开个人设备并联系网络信息中心。

网络信息中心当前联系方式见[校园网络介绍与连接指南](../)。IPv6 相关说明见[校内 IPv6 使用与排障](../ipv6/)。
