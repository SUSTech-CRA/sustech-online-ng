# 🖨️联创打印系统

学校自助文印系统提供打印、复印和扫描等功能。系统仅限校园网访问，当前统一入口为：

- [https://pms.sustech.edu.cn/](https://pms.sustech.edu.cn/)

::: warning 入口与旧教程

不要使用旧页面保存的裸 IP、HTTP 安装包或手工 DNS 地址。旧截图分别来自 2022 年前后的不同机型，按钮名称和流程可能已经变化；应以系统当前页面及设备屏幕提示为准。

:::

## 查找可用设备

校园各处的设备位置、纸型、彩色能力和状态会变化。登录联创打印系统后查看当前“打印点”或设备列表，不再依赖本站保存的全校静态清单。

图书馆当前公开的自助文印点包括：

| 图书馆 | 公开位置与类型 |
| --- | --- |
| 琳恩图书馆 | 一楼彩色、三楼彩色 |
| 一丹图书馆 | 一楼黑白；二楼服务台旁彩色、参考书区黑白 |
| 涵泳图书馆 | 一楼彩色 |

以上为图书馆网页当前展示的信息；使用前仍建议查看[图书馆自助文印页面](https://lib.sustech.edu.cn/zzwy/list.htm)和联创系统，确认设备可用状态、纸型与收费标准。

## 打印

1. 连接校园网后，通过 HTTPS 入口登录。
2. 按当前页面提示上传文件，或从系统页面下载适用于本人操作系统的官方客户端。不要从旧攻略中的 IP 地址或第三方网盘下载安装程序。
3. 上传前检查页码、纸张、单双面、颜色和份数；涉及个人信息或未公开材料时，确认系统的存储与删除提示。
4. 到所选设备按屏幕提示使用校园卡或当前支持的身份方式释放任务。
5. 取走全部纸张并退出账号；卡纸、缺纸或扣费异常时不要反复提交同一任务。

图书馆官网当前列出的价格为 A4 单面 0.1 元、A4 双面 0.2 元、A3 单面 0.2 元、A3 双面 0.4 元。价格可能调整，付款前以设备和系统显示为准；页面列出 A3 不代表每台设备当时都装有 A3 纸。

## 复印

携带校园卡和原稿到设备，选择复印功能后，根据屏幕设置纸型、单双面、缩放和份数。放置原稿时对齐设备上的尺寸标记，完成后取走原稿、成品和校园卡。

不同品牌设备的双面扫描顺序并不相同。若屏幕提示翻面或继续扫描，应先确认预览，再开始批量复印。

## 扫描

按设备当前提示选择扫描功能和接收方式。旧教程中的“邮件发送已失效”与“仍可继续添加邮件地址”互相矛盾，且不能代表所有机型；请以设备实际提供的校园账号文件夹、下载或邮件选项为准。

扫描含身份证件、成绩单、合同或研究数据的文件时：

- 确认接收账号属于本人；
- 先用一页测试分辨率、方向和多页合并方式；
- 下载完成后，按系统提供的方式删除服务器上的临时文件；
- 不将材料留在打印机玻璃板、出纸区或公共电脑中。
