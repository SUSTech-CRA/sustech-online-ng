# 🏥 就医与医保指南

::: danger 医疗急症

出现危及生命的症状或严重外伤时，请立即拨打 **120**，并清楚说明患者状况和具体位置。校内可同时拨打学校保卫部门 24 小时报警求助电话 **0755-88010110**，协助救护车进校；不要等待校内人员到场后再呼叫 120。详见[应急处理页面](/emergency/)。

:::

## 校内就医

- 校医务室（校园诊所）联系电话：**0755-88010120**。
- 门诊时间、药品和可开展项目可能调整，前往前建议先电话确认；校医务室不能替代 120 急救。
- 校医务室电话可在[南科大 2026 年校方会议服务页](https://icsa.sustech.edu.cn/)列示的校园医疗联系方式中复核；该页面是日期化信息，不是持续维护的医疗门户。

## 学生医保

::: warning 2026 年处于政策衔接期

深圳居民基本医疗保险正在调整缴费周期和办理方式。学校通知与医保部门后续通知可能随政策落地更新，不要再沿用本站旧版中的固定报销比例、年度额度或“默认转诊医院”等说法。

:::

根据学校发布的[2026 级新生医疗保险须知](https://osa.sustech.edu.cn/affairs/296.html)：

1. 学生应按学校当年通知完成参保或提交符合要求的不参保材料；不能在两地重复享受医保待遇。
2. 参保成功后，按规定使用金融社保卡或医保码就医。
3. 如需享受普通门诊统筹待遇，应先选定一家社康机构或其他基层医疗机构。常住校内的学生可按学校通知选择“南方科技大学社康服务中心”；选点范围和规则见深圳市医保局现行[就医管理办法](https://hsa.sz.gov.cn/gkmlpt/content/10/10863/post_10863181.html)。
4. 社康选点、参保信息和缴费明细可通过“深圳医保”微信公众号或[深圳市社会保险个人网上服务系统](https://sipub.sz.gov.cn/hspms/)查询办理。

深圳市医保局 2026 年 8 月发布的[居民基本医疗保险集中参保缴费通告](https://hsa.sz.gov.cn/fzlm/znts/cnyc/content/post_12958412.html)明确，自 2027 年起居民医保调整为按自然年度缴费，2026 年 9 月至 12 月为过渡期；在校学生的具体组织方式应继续以学校和医保部门最新通知为准。

## 看病前后建议确认

1. **先判断是否紧急。**危及生命时拨打 120；非紧急情况再选择校医务室、社康或医院门诊。
2. **确认医保状态。**在“深圳医保”中查看是否参保成功、医保码是否可用、普通门诊选点是否生效。
3. **确认机构和科室。**通过医疗机构官方渠道核对地址、出诊时间和预约方式，不依赖本站旧公交线路、旧挂号费或医院等级描述。
4. **保留材料。**妥善保存病历、处方、发票和费用清单；是否可报销、报销比例和所需材料以医保结算结果及医保部门答复为准。
