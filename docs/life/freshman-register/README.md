# 新生报到

::: warning 时效说明

新生报到安排每年更新。本页不再复用 2020 年的日期、金额、账号规则、联系人、地点和测试门槛。请以[南方科技大学新生入学服务网](https://welcome.sustech.edu.cn/)、随录取通知书提供的当年材料和迎新报到系统任务为准。
:::

- [南方科技大学新生入学服务网](https://welcome.sustech.edu.cn/)
- [当年入学指南](https://welcome.sustech.edu.cn/notices/1)
- [当年报到安排](https://welcome.sustech.edu.cn/notices/2)
- [当年新生军训通知](https://welcome.sustech.edu.cn/notices/3)
- [新生常见问题](https://welcome.sustech.edu.cn/notices/4)

本科新生报到系统请从官方迎新网顶部入口进入，避免使用往届材料中的账号、密码、时间和联系人。

## 报到前

请按照当年入学指南和迎新报到系统逐项确认：

1. 网上预报到和个人信息；
2. 书院及导师相关任务；
3. 缴费及银行卡事项；
4. 困难认定、绿色通道和助学贷款；
5. 党团组织关系；
6. 户籍迁移；
7. 当年度大学生医疗保险；
8. 兵役登记；
9. 学生档案；
10. 学生手册、安全教育及系统中显示的其他任务。

上述事项并非每名新生都适用，具体材料、截止时间和办理方式以当年官方通知为准。提前规划到校路线时，可以查看本站的[交通页面](/transport/)和[火车票学生优惠使用指南](/service/student-train-ticket/)。

## 现场报到

报到时间、地点及现场流程以[当年报到安排](https://welcome.sustech.edu.cn/notices/2)为准。随身携带身份证、录取通知书及官方清单要求的材料，不要将重要证件放入托运行李。

因故无法按时报到时，请使用[当年常见问题](https://welcome.sustech.edu.cn/notices/4)中公布的招生办公室联系方式，不要沿用往届联系人。

## 报到后

体检、住宿、校园卡、课程、开学教育和军训等后续安排，以学校及书院的当年通知为准。
