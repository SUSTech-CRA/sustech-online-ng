### 医疗与安全

- 危及生命的医疗急症：**立即拨打 120**；不要等待校内人员到场后再呼叫急救。
- 学校保卫部门 24 小时报警求助：**88010110**，可协助救护车进校和处理校内治安事件。
- 校医务室（校园诊所）：**88010120**，仅作校内医疗咨询或衔接，不能替代 120；门诊时间和服务项目请电话确认。
- 详细处理顺序见[应急处理](/emergency/)和[就医与医保指南](/service/medical-treatment/)。
