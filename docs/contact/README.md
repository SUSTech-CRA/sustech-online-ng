## 社区群聊（非官方）

截至 2026 年 8 月 31 日，本站无法可靠核验旧群号的当前用途、管理员身份和邀请链接归属。为避免号码被回收、群组改名或冒名管理员引导用户提交敏感信息，旧版 QQ 群号、直接加入链接、群收集问卷以及校外商家群列表不再作为当前黄页发布。

需要联系学校部门或办理事务时，请使用本页上方列出的官方电话、邮箱，并从[学校学生入口](https://www.sustech.edu.cn/zh/students.html)、[网上服务大厅](https://ehall.sustech.edu.cn/)或学校企业微信进入。查找学生组织时，可先查看[学生组织与社团](/organizations/)，再以校团委、学生工作部或组织当期官方招新通知为准。

::: warning 群聊安全

社区群聊不等同于学校官方渠道。加入前应通过可信同学、组织官网或学校通知交叉确认群名和管理员；不要向群内个人发送密码、验证码、身份证件、银行卡、医疗记录、未公开研究数据或付款码。涉及缴费、兼职、交易、外卖和失物招领时，优先使用可追溯的官方平台及线下服务点。

:::

旧群列表仍可在 Git 历史中查阅，但仅用于项目维护和历史考证，不建议据此加入群聊。
