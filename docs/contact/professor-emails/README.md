# 教师联系方式

::: warning 为什么不再维护静态邮箱表

本站旧表包含上千条教师邮箱和个人主页，其中有旧 `sustc.edu.cn` 地址、已变化的院系归属、无法确认的个人邮箱及明显拼写错误。人员和联系方式持续变动，继续复制静态表可能导致课程、科研或个人材料误投给无关收件人，因此本页自 2026 年起改用学校实时目录。

:::

## 当前查询入口

1. 在南方科技大学官网[全部教师列表](https://www.sustech.edu.cn/zh/colleges/)按姓名或院系查找教师。
2. 打开教师当前官方个人主页，只使用页面明确公开的邮箱或联系方式。
3. 如果个人主页没有公开邮箱，请进入教师所属院系官网联系院系办公室；学校当前院系入口可从[院系师资](https://www.sustech.edu.cn/zh/faculty_members.html)进入。
4. 仍无法确认时，可使用学校[联系电话目录](https://www.sustech.edu.cn/zh/contact_us.html)联系对应单位，不要根据姓名、旧域名或个人主页网址猜测邮箱。

## 发信前检查

- 核对姓名、院系、研究方向和收件地址是否来自同一份当前官方个人主页。
- 首封邮件避免附带身份证件、成绩单原件、未公开研究数据等不必要的敏感材料；确认收件人身份后再按要求补充。
- 不批量抓取、群发或传播教师联系方式。
- 若邮件退回或长期无回应，重新查询当前目录，不要把旧 `sustc.edu.cn` 地址机械替换成 `sustech.edu.cn` 后重发。

## 历史说明

原静态表是特定时期的社区整理结果，不再作为当前联系方式来源。需要考证历史人员信息时，请使用学校官网存档、院系新闻或互联网档案，并明确标注资料日期。
